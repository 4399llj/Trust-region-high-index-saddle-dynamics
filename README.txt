二维液晶（约化 Landau-de Gennes）复现代码
=======================================

来源：NLC_2D/NLC_2D。根目录保留原有二维模型及求解器，未改动算法。
新增 ldg_setup.m、run_ldg.m、validate_ldg.m 提供独立运行和验证入口。
data/nlcdata100/ 保留全部140个输入状态文件；读取前2*N个分量作为二维状态。
data/convergence_rate.mat 是原有历史数据，保留备查，不作为本次重新模拟结果。
legacy/ 保留原始主脚本、初始化脚本及其余顶层 .m 文件，供核对；
不要将 legacy/ 加入 MATLAB 路径，以免同名函数冲突。
原 test_nlc/test_nlc15 属于其他分量模型，依赖未随包提供的函数，不作为二维入口。

运行（将 MATLAB 当前目录设为本目录）：
  validate_ldg
  r = run_ldg('eigenspace','T1',6,500);
  r = run_ldg('CP','T1',6,100000);
  r = run_ldg('CPCG','T1',6,100000);
  r = run_ldg('HiSD','T1',6,100000);
也可 addpath 本目录后从其他目录调用，输入和输出均按入口文件位置定位。
run_ldg 默认仅计算 T1 的6维低特征子空间，对应原 main.m 的实际操作。
如需画最终状态：
  figure; drawnlc_2d(r.phi);
不要给 drawnlc_2d 传入第二个保存名称；原函数该分支使用旧保存路径。
结果保存至 results/；result.converged 根据最终残差重新判定，
eigenspace 模式只计算特征向量，不标记为鞍点搜索收敛。

模型参数：区域[-1,1]^2，h=1/50，内部99*99节点，两分量共19602自由度。
B=0.64e4，C=0.35e4，xi=-B^2/(2*C^2)，omega=50，E0=0。
内积为2*h^2*a'*b。CP/CPCG原始代码内部初始半径为[1e-3,1e-3]。
固定步长dt=1e-4，梯度容差1e-5；种子20261107。
解析 Hessian 统一兼容 H(u,v) 和初始化特征求解器的 H(u,v,l) 调用。

复现边界：
状态名称、目标指数和扰动决定具体景观跃迁。上面的T1/k=6是原始入口设置，
不代表已复现论文的全部连接关系。运行某一指定跃迁前须设置相应初态及扰动。
本次整理仅做模型导数和短程特征求解验证，未重跑全部长程鞍点搜索。
保留原始求解器的迭代计数方式，iter 不应直接当作严格更新次数比较。
未引入外部五分量模型和未提供的 hiosd_lobpcg/hiosd_sirqit 等历史依赖。
